Private Libraries

The plugin is opt-in: each user can turn on "Restrict my library" from the home-screen widget, after which they only see the media they requested through Jellyseerr or added from that widget. Users who never enable it keep seeing the full library.

Prefix for the per-user tag written onto granted items (e.g. jpl).
Off (default): the plugin is opt-in — each user is only restricted once they enable it from the widget. On: every user is restricted automatically and starts seeing nothing until granted something.

Base URL of your Jellyseerr instance, as reachable from the Jellyfin server. Required for syncing existing requests; the webhook does not use it.
Paste this same value into the Jellyseerr webhook payload's secret field. Leave empty to disable webhook processing.

Sync existing requests

The webhook only ever reports new activity. Add an API key here and the plugin will also read the requests already in Jellyseerr — including everything requested before this plugin was installed — and grant them to the matching Jellyfin user. It runs every 12 hours (see Scheduled Tasks → Sync Jellyseerr requests) and on demand with the button below.

From Jellyseerr → Settings → General → API Key. Leave empty to disable the sync and use the webhook only.
On (default): the scheduled task backfills grants every 12 hours. Off: only the "Sync now" button below runs it.
Off (default): only approved and completed requests are granted, matching what the webhook does. Declined and failed requests are never granted either way.

Jellyseerr webhook setup

In Jellyseerr → Settings → Notifications → Webhook, set the Webhook URL to <server>/PrivateLibraries/Webhook and use this JSON payload template: 

{
  "notification_type": "{{notification_type}}",
  "secret": "<your secret>",
  "media": {
    "media_type": "{{media_type}}",
    "tmdbId": "{{media_tmdbid}}",
    "tvdbId": "{{media_tvdbid}}"
  },
  "request": {
    "username": "{{requestedBy_username}}",
    "email": "{{requestedBy_email}}"
  }
}

Jellyseerr's default payload template also works — just add the secret field to it. The webhook accepts the requester as either request.username or request.requestedBy_username. Enable the Request Approved, Request Automatically Approved and Media Available notification types. If nothing is granted, the Jellyfin log states the reason.

Hidden media

Hide selected movies or series from every user except administrators. Hidden titles disappear from all non-admin libraries immediately, regardless of each user's own restriction setting. Changes take effect right away; the periodic reconcile task keeps them enforced.
